# Facebook Publisher

Plugin genérico para registrar varias páginas de Facebook y publicar imágenes en el feed o como historias. La configuración se administra desde la UI; los tokens de Página y secretos se cifran y nunca se devuelven al navegador.

El plugin usa `https://graph.facebook.com`, tareas ARQ durables y una política de publicación manual o automática por cuenta. No contiene reglas ni nombres de empresas.
