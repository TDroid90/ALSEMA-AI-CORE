# CreativoSur feature parity checklist

Legend: `planned`, `implemented`, `verified`, `blocked`.

| Capability | Source evidence | Target evidence | Status |
|---|---|---|---|
| One ALSEMA login and shell | standalone source UI/API | `/creativo` protected by ALSEMA auth | planned |
| Brands and brand policies | `brands/*.json` | creative brand API/UI and PostgreSQL | planned |
| Cometa G real-logo/no-price policy | schema and compositor tests | policy service and negative tests | planned |
| Manual/JSON/CSV catalog ingestion | `catalogs/adapters.py` | import service/API | planned |
| Google Sheets read-only boundary | export adapter and local snapshots | import contract; no write permission | planned |
| Product image download and thumbnails | source API | durable preparation task and asset endpoint | planned |
| Transparent cutout detection | compositor | compositor and QA tests | planned |
| `rembg` cutout generation | source API | creative worker task | planned |
| Deterministic Pillow rendering | `composer.py` | creative compositor | planned |
| Template A: Product Hero | variant A | native preset A | planned |
| Template B: Gaming/Performance | variant B | native preset B | planned |
| Template C: Clean Tech | requested consolidation extension | native preset C | planned |
| Formats 1080×1350, story, square, horizontal | `FORMATS` | validated format catalog | planned |
| Layer positioning and scaling | product generator UI | `/creativo` editor | planned |
| Up to three product images | source generator | `/creativo` editor | planned |
| Professional template layer editor | `editor.tsx` | `/creativo/templates/:id` | planned |
| Text/image/shape layers | editor | native editor | planned |
| Undo/redo, duplicate, z-order, lock/visibility | editor | native editor | planned |
| Fonts, color, alignment and transforms | editor | native editor | planned |
| JSON import/export and PNG export | editor | native editor | planned |
| Saved template library | template API | PostgreSQL-backed library | planned |
| Preview generated by production compositor | `/creative-preview` | authenticated preview API | planned |
| Final generation and manifests | `/creative-jobs` | durable ARQ job | planned |
| QA validation and checksums | compositor manifest | asset/QA persistence | planned |
| Pending approval by default | SQLite job status | PostgreSQL job state machine | planned |
| Human approve/reject | decision endpoint | RBAC-protected approval endpoint | planned |
| History and asset inspection | source job/output files | jobs/assets UI | planned |
| ComfyUI health and optional enhancement | local visual provider | provider-neutral visual port | planned |
| SSD/FLUX configuration compatibility | source docs | configurable ComfyUI workflow/model metadata | planned |
| Ollama text assistance | requested target | ALSEMA provider integration | planned |
| LM Studio optional fallback | source provider | optional provider contract/configuration | planned |
| No automatic social publishing | dry-run source adapters | no publisher call from creative module | planned |
| Durable progress/retry/cancel | absent in source | ALSEMA task engine | planned |
| Import existing SQLite/templates/catalog/assets | source data | idempotent migration command/report | planned |
| Unit, integration and E2E coverage | source and ALSEMA tests | consolidated test suites | planned |
| Docker-only ALSEMA deployment | separate source scripts | one `docker compose up -d --build` | planned |

Parity is declared only after target evidence is executable. A migrated screen without its backend path, permission, persistence, and tests does not count.
